🐛 TROUBLESHOOTING
==================

"Module not found: dotenv"
→ pip install python-dotenv

"Email Error: Invalid login credentials"
→ Check 16-char app password (not regular Gmail password)

"SMTP connection failed"
→ Check internet, verify SMTP_PORT=465

"Database locked"
→ Delete email_subscribers.db and restart

For more help, see: EMAIL_SETUP_GUIDE.md
