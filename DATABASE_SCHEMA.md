# Database Schema - AtmoSense Email System

## PostgreSQL Schema (Supabase)

```sql
CREATE TABLE email_subscribers (
    id bigint generated by default as identity primary key,
    email text unique not null,
    subscribed boolean default true,
    frequency text default 'daily',
    created_at timestamp with time zone default now(),
    last_sent timestamp with time zone
);
```

## Table Description

| Column | Type | Description |
|--------|------|-------------|
| `id` | bigint (PK) | Auto-incrementing primary key |
| `email` | text (UNIQUE) | Subscriber email address |
| `subscribed` | boolean | Subscription status (true = active) |
| `frequency` | text | Notification frequency (daily, hourly, weekly) |
| `created_at` | timestamp | Account creation timestamp |
| `last_sent` | timestamp | Last email send timestamp |

## Indexes

Primary key on `id` is created automatically. Unique constraint on `email` prevents duplicates.

## Connection

The application connects via:
```
DATABASE_URL=postgresql://user:password@host:port/database
```

Set in `.env` file from Supabase dashboard.

## Sample Queries

### Get all active subscribers
```sql
SELECT email, frequency FROM email_subscribers WHERE subscribed = true;
```

### Get subscriber count
```sql
SELECT COUNT(*) FROM email_subscribers WHERE subscribed = true;
```

### Update last sent timestamp
```sql
UPDATE email_subscribers SET last_sent = now() WHERE email = 'user@example.com';
```

### Reactivate subscriber
```sql
UPDATE email_subscribers SET subscribed = true WHERE email = 'user@example.com';
```

### Delete all unsubscribed
```sql
DELETE FROM email_subscribers WHERE subscribed = false;
```

## Notes

- Uses PostgreSQL's `generated by default as identity` for auto-increment
- Timestamps use `with time zone` for UTC handling
- `subscribed` field allows soft deletes (flag as inactive rather than delete)
- `last_sent` tracks for scheduling and analytics
- Email addresses stored in lowercase for consistency
