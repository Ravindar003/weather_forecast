🐛 COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════

"Module not found: dotenv"
→ pip install python-dotenv

"Email Error: Invalid login credentials"
→ Check 16-char app password (not regular Gmail password)

"SMTP connection refused"
→ Verify internet connection, check SMTP settings

"Database locked"
→ Delete email_subscribers.db and restart

"Email not received"
→ Check spam folder, verify recipient email

For more troubleshooting: See EMAIL_SETUP_GUIDE.md
